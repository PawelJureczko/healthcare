> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the Laravel 12 + Inertia + Vue 3 + Tailwind monolith with Docker Compose dev environment, two-account seeded auth (no public registration), `user_id` data isolation enforced by a global scope, per-user editable profiles, an app layout, and a PWA installable on iPhone with an empty per-user dashboard.

Local dev runs on Laravel Sail (Docker Compose). PWA installability comes from `vite-plugin-pwa`.

**Tech Stack:** Laravel 12, Laravel Sail (Docker Compose), Laravel Breeze (Inertia + Vue 3 Composition API stack), Tailwind CSS, MySQL 8, Pest (testing), vite-plugin-pwa.

## Task 4: `user_id` global scope mechanism (`BelongsToUser` trait)

This is the core M0 deliverable per spec §6: "wszystkie tabele danych osobistych ... mają kolumnę `user_id` i globalny scoping per zalogowany użytkownik od M0". Build the reusable mechanism now; every personal-data model from M1 onward uses it.

**Files:**
- Create: `app/Models/Scopes/UserOwnedScope.php`
- Create: `app/Models/Concerns/BelongsToUser.php`
- Test: `tests/Feature/DataIsolationTest.php`

**Interfaces:**
- Produces: trait `BelongsToUser` — any Eloquent model that `use`s it gets (a) a global scope filtering `where user_id = auth()->id()` whenever a user is authenticated, (b) automatic `user_id` assignment on `creating`, (c) a `user(): BelongsTo` relation. Later tasks' `Profile` model (Task 5) consumes this trait directly.

- [ ] **Step 1: Write the global scope class**

Create `app/Models/Scopes/UserOwnedScope.php`:

```php
<?php

namespace App\Models\Scopes;

use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Scope;
use Illuminate\Support\Facades\Auth;

class UserOwnedScope implements Scope
{
    public function apply(Builder $builder, Model $model): void
    {
        if (Auth::check()) {
            $builder->where($model->getTable().'.user_id', Auth::id());
        }
    }
}
```

- [ ] **Step 2: Write the `BelongsToUser` trait**

Create `app/Models/Concerns/BelongsToUser.php`:

```php
<?php

namespace App\Models\Concerns;

use App\Models\Scopes\UserOwnedScope;
use App\Models\User;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Support\Facades\Auth;

trait BelongsToUser
{
    public static function bootBelongsToUser(): void
    {
        static::addGlobalScope(new UserOwnedScope);

        static::creating(function ($model) {
            if (! $model->user_id && Auth::check()) {
                $model->user_id = Auth::id();
            }
        });
    }

    public function user(): BelongsTo
    {
        return $this->belongsTo(User::class);
    }
}
```
