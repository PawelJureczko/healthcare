# M3 — Siłownia — plan implementacji

> **Dla agentów wykonawczych:** WYMAGANY PODSKILL: użyj superpowers:subagent-driven-development
> (rekomendowane) lub superpowers:executing-plans do wykonania tego planu zadanie po zadaniu.
> Kroki używają składni checkbox (`- [ ]`) do śledzenia postępu.

**Cel:** Słownik ćwiczeń z flagą ryzyka lędźwiowego, ręczne tworzenie treningu siłowego
(plany AI dojdą w M4), live-logger (odhaczanie serii, timer przerw, podpowiedź poprzedniego
ciężaru, kolejka localStorage odporna na słaby zasięg), ocena pleców 0–10 + samopoczucia po
treningu, historia progresji per ćwiczenie z wykresem.

**Architektura:** Trzeci typ treningu (`type=gym`) w istniejącej wspólnej tabeli `workouts`
(z M2) — kolumna `type` jest `string`, więc dodanie nowej wartości nie wymaga migracji zmiany
schematu, tylko rozszerzenia walidacji. Nowe tabele podrzędne `gym_exercises` (ćwiczenia w
ramach treningu, N na workout) i `gym_sets` (serie w ramach ćwiczenia) — bez własnego `user_id`,
izolacja dziedziczona przez `workout_id`/`gym_exercise_id`, dokładnie ten sam wzorzec co
`Run`/`SportSession` z M2 i `LabValue` z M1. `exercises` to **wspólny słownik** (bez
`user_id`/`BelongsToUser`), analogicznie do `lab_markers` z M1 — predefiniowane ćwiczenia +
możliwość dodania własnych. Live-logger to strona Vue z kolejką mutacji w `localStorage`:
zapis serii jest optymistyczny (UI aktualizuje się natychmiast), a żądanie PATCH do backendu
jest wysyłane w tle przez `axios` — przy błędzie sieci trafia do kolejki i jest ponawiane po
odzyskaniu połączenia.

**Tech Stack:** Laravel 12, Inertia.js + Vue 3 (Composition API), MySQL 8, Tailwind CSS,
Chart.js/vue-chartjs (`LineChart.vue` z M1), `axios` (już skonfigurowany globalnie w
`resources/js/bootstrap.js` — używany zamiast `fetch()` dla mutacji live-loggera, bo automatycznie
dołącza token CSRF z ciasteczka `XSRF-TOKEN`, tak jak reszta aplikacji), `localStorage` (kolejka
offline), Pest.

**Spec:** [`specyfikacja.md`](../../../specyfikacja.md) — §4.3 (Siłownia), §6 (model danych:
`exercises`, `gym_exercises`, `gym_sets`, kolumna `back_pain_rating` na `workouts`), §8 (M3 —
kryteria ukończenia).

## Global Constraints

- Cały tekst widoczny dla użytkownika — po polsku. Wyjątek: komunikaty walidacji Laravela
  zostają po angielsku (`APP_LOCALE=en`, patrz `CLAUDE.md`).
- **`exercises` to tabela WSPÓLNA** — bez `user_id`, bez `BelongsToUser` — widoczna dla obojga
  użytkowników, analogicznie do `lab_markers` (M1). NIE dodawaj do niej scope'a.
- **`gym_exercises` i `gym_sets` są tabelami podrzędnymi** — bez własnego `user_id`, bez
  `BelongsToUser`. Izolacja jest dziedziczona: `gym_exercises` przez `workout_id` (analogicznie
  do `Run`/`SportSession` z M2), `gym_sets` przez `gym_exercise_id` → `workout_id`. Odczyty
  zawsze idą przez `Workout::forUser($user)->with('gymExercises.gymSets')`, nigdy przez
  bezpośrednie zapytanie do `GymExercise::`/`GymSet::`.
- **Krytyczne — endpoint mutujący `gym_sets` (PATCH `/gym-sets/{gymSet}`) MUSI jawnie
  weryfikować właściciela.** To pierwszy w tej aplikacji endpoint, który **modyfikuje** zasób
  podrzędny bez własnego scope'a (dotychczasowe podrzędne zasoby z M1/M2 były tylko do odczytu).
  Bez jawnej weryfikacji użytkownik A mógłby modyfikować serię należącą do treningu użytkownika
  B, podając dowolne `id`. Wymagana weryfikacja:
  `abort_unless($gymSet->gymExercise->workout->user_id === $request->user()->id, 404);`
  na samym początku metody kontrolera, przed jakąkolwiek modyfikacją. Musi być pokryta testem
  (`user cannot update another user's gym set` — oczekiwane 404).
- Kolumny typu-wyliczeniowego (`status` na `gym_sets`) to `string`, NIE natywny MySQL `ENUM` —
  zgodnie z konwencją ustaloną w M2 (`workouts.type`/`workouts.status`/`workouts.sport_subtype`).
- Modele z atrybutem typu `date` dostają override `serializeDate()` → `Y-m-d` (konwencja z M1) —
  `Workout` już to ma z M2, żaden nowy model w tym planie nie dodaje własnego atrybutu `date`.
- Formularze dat w Vue używają `localDate()` z `resources/js/localDateTime.js` (M1) —
  nigdy `new Date().toISOString()`.
- Mutacje live-loggera (`PATCH /gym-sets/{id}`) idą przez `window.axios`, NIE `fetch()` — axios
  jest już globalnie skonfigurowany w `resources/js/bootstrap.js` i automatycznie dołącza
  nagłówek CSRF z ciasteczka `XSRF-TOKEN`, dokładnie tak jak każde inne żądanie w tej aplikacji.
  Wprowadzenie `fetch()` wymagałoby ręcznego dociągania tokenu CSRF z meta-tagu, którego ta
  aplikacja nie ma (Inertia/axios obsługują to przez ciasteczko) — nie dodawaj takiego meta-tagu,
  użyj `axios`.
- Weryfikacja kolejki offline w `localStorage` jest częściowo poza zasięgiem Pest (logika czysto
  kliencka, zależna od `window`/`localStorage`/zdarzeń sieciowych przeglądarki) — backendowy
  endpoint PATCH jest w pełni pokryty testami Pest; sama kolejka JS jest weryfikowana przez
  code review i ręczny test z DevTools (throttling/offline), analogicznie do sposobu, w jaki M0
  odłożyło weryfikację PWA na fizycznym iPhonie do ręcznej kontroli użytkownika.

<?php

use App\Models\Exercise;
use App\Models\GymExercise;
use App\Models\GymSet;
use App\Models\User;
use App\Models\Workout;

test('a gym exercise belongs to its workout and exercise, with no user_id column of its own', function () {
    $workout = Workout::factory()->create(['type' => 'gym']);
    $exercise = Exercise::factory()->create();
    $gymExercise = GymExercise::factory()->for($workout)->for($exercise)->create();

    expect($gymExercise->workout->id)->toBe($workout->id)
        ->and($gymExercise->exercise->id)->toBe($exercise->id)
        ->and($gymExercise->getAttributes())->not->toHaveKey('user_id');
});

test('a gym set belongs to its gym exercise, with no user_id column of its own', function () {
    $gymExercise = GymExercise::factory()->create();
    $gymSet = GymSet::factory()->for($gymExercise)->create();

    expect($gymSet->gymExercise->id)->toBe($gymExercise->id)
        ->and($gymSet->getAttributes())->not->toHaveKey('user_id');
});

test('gym exercise isolation is inherited transitively through workout_id', function () {
    $userA = User::factory()->create();
    $userB = User::factory()->create();

    $workoutA = Workout::factory()->for($userA)->create(['type' => 'gym']);
    $workoutB = Workout::factory()->for($userB)->create(['type' => 'gym']);
    GymExercise::factory()->for($workoutA)->create();
    GymExercise::factory()->for($workoutB)->create();

    $this->actingAs($userA);

    // GymExercise has no scope of its own — documents the expected,
    // safe-by-design behavior: callers MUST filter through Workout::forUser().
    expect(GymExercise::count())->toBe(2);

    $isolated = Workout::forUser($userA)->where('type', 'gym')->with('gymExercises')->get();
    expect($isolated)->toHaveCount(1)
        ->and($isolated->first()->gymExercises)->toHaveCount(1);
});

test('exercises are a shared dictionary visible to both users', function () {
    $userA = User::factory()->create();
    $userB = User::factory()->create();
    Exercise::factory()->create(['name' => 'Przysiad testowy']);

    $this->actingAs($userA);
    expect(Exercise::count())->toBe(1);

    $this->actingAs($userB);
    expect(Exercise::count())->toBe(1);
});

<?php

namespace App\Services;

use App\Models\User;
use App\Models\Workout;

class ExerciseHistory
{
    /**
     * @param  array<int>  $exerciseIds
     * @return array<int, float|null>
     */
    public static function lastWeights(User $user, array $exerciseIds): array
    {
        $latestWorkoutDates = [];

        $workouts = Workout::forUser($user)
            ->where('type', 'gym')
            ->with(['gymExercises' => function ($query) use ($exerciseIds) {
                $query->whereIn('exercise_id', $exerciseIds)->with('gymSets');
            }])
            ->orderByDesc('date')
            ->get();

        $result = array_fill_keys($exerciseIds, null);

        foreach ($workouts as $workout) {
            foreach ($workout->gymExercises as $gymExercise) {
                $exerciseId = $gymExercise->exercise_id;

                if ($result[$exerciseId] !== null) {
                    continue;
                }

                $maxWeight = $gymExercise->gymSets
                    ->where('status', 'done')
                    ->max('weight_kg');

                if ($maxWeight !== null) {
                    $result[$exerciseId] = (float) $maxWeight;
                }
            }
        }

        return $result;
    }
}

<?php

namespace App\Http\Controllers;

use App\Http\Requests\StoreGymWorkoutRequest;
use App\Models\Exercise;
use App\Models\Workout;
use App\Services\ExerciseHistory;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\DB;
use Inertia\Inertia;
use Inertia\Response;

class GymWorkoutController extends Controller
{
    public function create(Request $request): Response
    {
        $exercises = Exercise::orderBy('muscle_group')->orderBy('name')->get();
        $lastWeights = ExerciseHistory::lastWeights($request->user(), $exercises->pluck('id')->all());

        return Inertia::render('GymWorkouts/Create', [
            'exercises' => $exercises,
            'lastWeights' => $lastWeights,
        ]);
    }

    public function store(StoreGymWorkoutRequest $request): RedirectResponse
    {
        $data = $request->validated();

        $workout = DB::transaction(function () use ($request, $data) {
            $workout = $request->user()->workouts()->create([
                'type' => 'gym',
                'date' => $data['date'],
                'status' => 'planned',
            ]);

            foreach ($data['exercises'] as $order => $exerciseData) {
                $gymExercise = $workout->gymExercises()->create([
                    'exercise_id' => $exerciseData['exercise_id'],
                    'order' => $order,
                ]);

                foreach ($exerciseData['sets'] as $setIndex => $setData) {
                    $gymExercise->gymSets()->create([
                        'set_number' => $setIndex + 1,
                        'planned_weight_kg' => $setData['planned_weight_kg'] ?? null,
                        'planned_reps' => $setData['planned_reps'],
                        'status' => 'pending',
                    ]);
                }
            }

            return $workout;
        });

        return redirect()->route('gym-workouts.show', $workout);
    }
}

```js
// Offline-resilient queue for live-logger set updates. Optimistic UI
// updates the local state immediately; the PATCH to the backend goes
// through axios (already configured with CSRF handling in bootstrap.js).
// On network failure, the mutation is queued in localStorage and retried
// on the next 'online' event or the next call to drainQueue().

const QUEUE_KEY = 'gym-set-queue';

function readQueue() {
    try {
        return JSON.parse(localStorage.getItem(QUEUE_KEY)) ?? [];
    } catch {
        return [];
    }
}

function writeQueue(queue) {
    localStorage.setItem(QUEUE_KEY, JSON.stringify(queue));
}

export function enqueueSetUpdate(gymSetId, payload) {
    const queue = readQueue();
    queue.push({ gymSetId, payload });
    writeQueue(queue);
}

export async function drainQueue() {
    const queue = readQueue();

    for (let i = 0; i < queue.length; i++) {
        try {
            await window.axios.patch(`/gym-sets/${queue[i].gymSetId}`, queue[i].payload);
        } catch {
            writeQueue(queue.slice(i));
            return;
        }
    }

    writeQueue([]);
}

export async function updateGymSet(gymSetId, payload) {
    try {
        await window.axios.patch(`/gym-sets/${gymSetId}`, payload);
        return true;
    } catch {
        enqueueSetUpdate(gymSetId, payload);
        return false;
    }
}
```

<?php

namespace App\Http\Controllers;

use App\Models\Exercise;
use App\Models\Workout;
use Illuminate\Http\Request;
use Inertia\Inertia;
use Inertia\Response;

class ExerciseProgressionController extends Controller
{
    public function show(Request $request, Exercise $exercise): Response
    {
        $sessions = Workout::forUser($request->user())
            ->where('type', 'gym')
            ->whereHas('gymExercises', fn ($query) => $query->where('exercise_id', $exercise->id))
            ->with(['gymExercises' => fn ($query) => $query->where('exercise_id', $exercise->id)->with('gymSets')])
            ->orderBy('date')
            ->get()
            ->map(function ($workout) {
                $maxWeight = $workout->gymExercises
                    ->flatMap(fn ($gymExercise) => $gymExercise->gymSets)
                    ->where('status', 'done')
                    ->max('weight_kg');

                return [
                    'date' => $workout->date->format('Y-m-d'),
                    'maxWeightKg' => $maxWeight !== null ? (float) $maxWeight : null,
                ];
            })
            ->filter(fn ($session) => $session['maxWeightKg'] !== null)
            ->values();

        return Inertia::render('Exercises/Progression', [
            'exercise' => ['id' => $exercise->id, 'name' => $exercise->name],
            'sessions' => $sessions,
        ]);
    }
}
